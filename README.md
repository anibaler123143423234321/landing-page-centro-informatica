# 🌐 Landing Page Centro de Informática USS (Versión HTML Estática Limpia)

Copia completa, desacoplada y 100% estática (HTML, CSS, JavaScript Vanilla e Imágenes locales) extraída de la plantilla **Poolix** (`https://poolix-one.vercel.app/?storefront=envato-elements`).

> **Nota:** Esta carpeta es **100% HTML/CSS/JS puro**, sin React, sin Vite, sin Node.js y sin `node_modules`.

---

## 🚀 Cómo Ver o Abrir la Landing Page

1. **Directamente en tu Navegador (Sin servidor)**:
   - Haz doble clic sobre [`index.html`](file:///Users/dagnerchumanlluen/Documents/USS/landing-page-centro-informatica/index.html) desde Finder o tu explorador de archivos.
   - Todos los estilos CSS, imágenes y enlaces internos funcionan con rutas relativas locales.

2. **Con cualquier servidor web ligero**:
   - Con Python:
     ```bash
     cd /Users/dagnerchumanlluen/Documents/USS/landing-page-centro-informatica
     python3 -m http.server 8080
     ```
     Y abre `http://localhost:8080` en tu navegador.
   - Con la extensión Live Server de VSCode / Antigravity IDE:
     - Haz clic derecho sobre `index.html` > "Open with Live Server".
